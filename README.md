## 🚚 Featured Project: Logistics Data Warehouse

An end-to-end data warehousing project built using the **Medallion Architecture (Bronze → Silver → Gold)** to transform raw logistics data into structured datasets for analytics and reporting.

### Current Progress

- Designed the data warehouse architecture and dimensional models.
- Loaded raw customer, shipment, and logistics performance datasets into the Bronze layer.
- Profiled source data and investigated data quality issues.
- Cleaned and standardised data in the Silver layer.
- Handled malformed records, inconsistent values, data type issues, and duplicates.
- Built Gold dimension and fact views for analytics.
- Used SQL joins to integrate dimensional and transactional data.
- Implemented Python-based ETL components for extraction, Bronze loading, database connectivity, logging, and pipeline orchestration through project collaboration.
- Documented architecture, transformations, and data quality decisions.

**Current stage:** Gold layer views completed. Further ETL automation and analytics development in progress.
